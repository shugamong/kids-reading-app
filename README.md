📖 아이랑 엄마랑 독서 달력 (Kids Reading App)
아이와 함께 책을 읽고 날짜별로 독후 활동을 기록하는 안드로이드(Android) 모바일 앱 프로젝트입니다. 인터넷 연결 없이도 스마트폰 내부 저장소에 안전하게 기록이 보관되며, GitHub Actions를 통해 클라우드에서 자동으로 .apk 파일로 빌드됩니다.

📁 1. 프로젝트 파일 구성 및 역할
이 프로젝트는 총 4개의 핵심 파일로 구성되어 있습니다.

① App.js (앱 메인 소스 코드)
역할: 앱의 화면 UI, 기능, 데이터 저장을 담당하는 핵심 프로그램 파일입니다.

주요 기능:

한글 달력 화면 (react-native-calendars): 날짜별 독후 활동 기록 여부 표시 및 터치 시 작성/수정 창 오픈.

카메라 & 갤러리 연동 (expo-image-picker): 책 표지나 아이가 독서하는 모습을 직접 촬영하거나 갤러리에서 선택해 첨부.

입력 폼: 책 제목, 저자, 5점 만점 별점, 기분 스티커, 줄거리 요약, 그리고 아이의 느낀 점과 엄마의 느낀 점을 각각 분리해서 기록.

연속 독서 스트릭 (Streak): 매일 꾸준히 책을 읽을 때마다 연속 독서 일수를 계산하여 화면에 표시.

로컬 저장소 (AsyncStorage): 스마트폰 내부 저장소에 데이터를 저장하여 인터넷이 없는 환경에서도 작동.

② package.json (프로젝트 설정 및 의존성 관리)
역할: 이 앱을 구동하는 데 필요한 외부 라이브러리(달력, 카메라, 저장소 등)의 목록과 버전을 정의하는 설정 파일입니다.

내용 요약: React Native, Expo, 그리고 위젯 및 UI 구동에 필요한 라이브러리(react-native-calendars, expo-image-picker 등)들이 명시되어 있어, 빌드 시 컴퓨터가 어떤 재료가 필요한지 알려줍니다.

③ package-lock.json (패키지 버전 잠금 파일)
역할: package.json에 기록된 라이브러리들의 정확한 하위 버전과 의존성 관계를 고정시키는 파일입니다.

이유: 빌드 서버(클라우드)에서 패키지를 설치할 때 버전 충돌이나 에러 없이 항상 똑같은 환경에서 안정적으로 빌드가 이루어지도록 보장합니다.

④ .github/workflows/build-apk.yml (자동 빌드 파이프라인 설정)
역할: GitHub의 클라우드 컴퓨터(Actions)에게 "이 코드를 안드로이드 앱 설치 파일(.apk)로 조립해 줘"라고 명령하는 자동화 시나리오 설정 파일입니다.

작동 타이밍: 사용자가 수동으로 빌드 버튼을 누를 때(workflow_dispatch) 실행됩니다.

⚙️ 2. GitHub Actions에서 APK로 빌드되는 과정
내 컴퓨터에 안드로이드 앱 개발 프로그램(Android Studio 등)을 설치하지 않아도, GitHub의 무료 클라우드 서버가 대신 앱을 만들어 주는 과정은 다음과 같습니다.

클라우드 환경 준비 (ubuntu-24.04):

GitHub이 가상의 고성능 리눅스 컴퓨터 한 대를 잠시 빌려줍니다.

개발 도구 세팅 (Node.js & Java JDK):

리눅스 서버 위에 앱을 빌드할 수 있는 Node.js(자바스크립트 실행 환경)와 Java JDK(안드로이드 컴파일 필수 도구)를 자동으로 설치합니다.

필수 라이브러리 다운로드 (npm install):

package.json과 package-lock.json을 읽고, 앱 구동에 필요한 모든 모듈을 인터넷에서 내려받습니다.

안드로이드 프로젝트 변환 (npx expo prebuild):

순수 자바스크립트로 작성된 React Native 코드를 안드로이드 시스템이 이해할 수 있는 네이티브 안드로이드 프로젝트 구조(/android 폴더)로 자동 변환합니다.

APK 파일 컴파일 (./gradlew assembleRelease):

안드로이드 빌드 도구(Gradle)가 소스 코드와 리소스를 모아 실제 스마트폰에 설치할 수 있는 최종 설치 파일인 app-release.apk를 빚어냅니다.

결과물 업로드 (upload-artifact):

완성된 .apk 파일을 GitHub 서버에 안전하게 업로드하여, 사용자가 웹 화면에서 클릭 한 번으로 다운로드할 수 있게 제공합니다.

빌드가 성공적으로 끝나면 Actions 페이지의 Artifacts에서 파일을 내려받아 아이의 안드로이드 폰에 바로 설치하시면 됩니다!
